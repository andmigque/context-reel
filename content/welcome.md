# Welcome to Context Reel

Context Reel is a Markdown workspace for working with context.

Write and edit documents in the **Editor**, explore their structure in the **Mark Map**, and send any selected text into **Chat** as a **Zap**.

Markdown is the native language here, so headings, lists, tables, links, and fenced code blocks all render normally.

## One conversation, many models

Choose which model answers each turn, and switch models whenever you like, even in the middle of a conversation.

There is still only **one shared thread**. Every model receives the full conversation history, including answers written by the other models.

Earlier assistant messages do not include reliable model attribution. A model usually cannot tell whether a response came from GPT, Claude, Gemini, Grok, or itself. When authorship matters, write it directly into the message.

## Let the models work together

Models are free to respond to ideas already introduced by other models.

They can:

- Build on an earlier answer
- Correct a mistake
- Challenge an assumption
- Offer a different approach
- Combine several answers into something stronger

The goal is not to manufacture a debate. It is to let multiple models work openly inside the same context.

## Start somewhere

Open a document from the Zap Rail, edit it, select the part you want to discuss, and Zap it into the chat.

The document holds the context. The models help you operate on it.
